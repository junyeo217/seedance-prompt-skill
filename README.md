# Seedance Prompt Skill

현재 사용 중인 `seedance 0.1.1+local.5`의 독립 보관본입니다. Seedance 2.5 프롬프트 작성·검토·원문 전달·부분 편집을 지원합니다.

## 구성과 사용

- 진입점: [SKILL.md](SKILL.md)
- 생성·참조, 키프레임·스토리보드, 편집·연장, 연기·카메라·오디오 지침: `references/`
- 출처 및 통합 내역: [source-and-change-map.md](references/source-and-change-map.md)

이 저장소를 로컬에 복제한 뒤 에이전트가 `SKILL.md`를 읽도록 지정하거나, 복제 폴더를 해당 에이전트의 스킬 디렉터리에 `seedance`라는 이름으로 연결합니다. 기존 설치가 있다면 덮어쓰기 전에 비교하세요.

출력은 프롬프트 텍스트와 검토 결과입니다. 영상 생성, 업로드, 모델 호출과 계정 설정은 포함하지 않습니다.

## 출처와 보존 범위

공식 `sd25-pe 0.1.1`과 출처표에 기록된 자료를 바탕으로 구성한 로컬 개선본이며, 공식 업스트림 릴리스가 아닙니다. 출처표의 원문 해시와 통합 내역을 보존합니다. 원본 ZIP에 별도 LICENSE가 없다는 기존 기록을 유지하며 이 보관본에 새 라이선스를 부여하지 않습니다.

2026-09-28 설치본의 스킬 파일을 복사하고 공개용 사본에서 개인 절대 경로를 PROJECT_ROOT·USER_HOME 표기로 바꿨습니다. 이 표기는 외부 원본 위치를 설명하는 자리표시자이며 저장소 내부 링크가 아닙니다. 출처표의 파일 해시는 수정 전 원본 기준입니다. 출처표에 나오는 개인 프로젝트의 원본 파일과 외부 검수 기록은 이 저장소에 동봉되지 않았으며, 원본의 위치를 기록하는 용도입니다. 과거 검수 서술은 해당 시점의 기록이며 이번 업로드가 새 모델 실행·렌더 검증을 뜻하지 않습니다.
